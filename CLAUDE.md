# Synesthesia Visualizer

A browser app that listens through the mic and turns music into visuals:
pitch → color, timbre → shape, loudness → size. Goal: help people without
synesthesia "see" music, especially when learning an instrument or singing.

## Stack
Plain HTML + JavaScript, Web Audio API, Canvas. No frameworks for now.

## How to work with me
- This is a learning + portfolio project. I want to understand every line.
- Explain the concept BEFORE writing code. Keep changes small (one feature at a time).
- When reasonable, let me write the code first and then review it.
- After each feature, suggest a short git commit message.

## Roadmap
1. Mic → circle that grows with loudness
2. Pitch detection → show note name
3. Note → color mapping
4. Timbre → shape
5. Learning mode (target note, sharp/flat in cents)
6. Settings panel, polish, deploy to GitHub Pages
